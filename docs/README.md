## Como planejamos

Planejamento é conversa, o tempo todo — não só no começo.

- Você traz ideias; o **agente pergunta, opina e sugere** o que estiver faltando (produto, API, stack).
- Nada vira “decidido” nos docs sem confirmação.
- Quando algo fechar, atualiza-se o arquivo certo e sai de [open.md](open.md).
- Código (Java, Docker, deps novas) só quando você pedir para implementar.
